# Sistema de Gestión con PostgreSQL y Java

Proyecto final del curso de Base de Datos 1. Se realizó el diseño e implementación de una base de datos utilizando PostgreSQL, incluyendo un modelo conceptual (ERD), esquema relacional, diccionario de datos y restricciones de integridad referencial. También se desarrolló una aplicación de escritorio en Java y Swing con operaciones CRUD, procesos de negocio, manejo de transacciones y generación de informes.
